05 / ABOUT

关于小鸦的制品

不依赖 token

制品本身开放浏览、下载和使用说明；桌宠翻译默认使用系统能力与免密钥翻译，不把 token 带进制品。

跨设备

静态站，手机、平板、电脑都能打开。没有同网络限制，也没有本地端口要求。

可持续更新

版本、补丁与 SHA-256 清单集中发布；插件更新器从制品站拉取，不必重新发一整包给每台电脑。
